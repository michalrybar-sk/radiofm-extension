# Privacy Policy – Rádio FM Player

## English

This extension does not collect, store, or transmit any personal data.

The only data stored locally is the user's volume preference, 
saved using Chrome's storage API on the user's own device.

No data is shared with third parties.

## Slovensky

Toto rozšírenie nezbiera, neukladá ani neodosiela žiadne osobné údaje.

Jediný údaj uložený lokálne je nastavenie hlasitosti používateľa,
uložené pomocou Chrome storage API priamo na zariadení používateľa.

Žiadne údaje nie sú zdieľané s tretími stranami.
