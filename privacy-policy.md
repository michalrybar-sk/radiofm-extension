## Slovensky

Toto rozšírenie nezbiera, neukladá ani neodosiela žiadne osobné údaje.

Údaje uložené lokálne na zariadení používateľa:
- Nastavenie hlasitosti
- Názvy položiek archívu relácií
- História prehratých položiek archívu

Všetky údaje sú uložené pomocou Chrome storage API 
priamo na zariadení používateľa.
Žiadne údaje nie sú zdieľané s tretími stranami.

## English

This extension does not collect, store, or transmit any personal data.

Data stored locally on the user's device:
- Volume preference
- Archive show item names
- History of played archive items

All data is stored using Chrome's storage API 
directly on the user's own device.
No data is shared with third parties.
